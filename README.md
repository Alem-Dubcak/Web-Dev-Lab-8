# Student Performance Management System

## Project Description

The Student Performance Management System is a full-stack web application that allows educators to add, view, update, and delete student academic records.

## Technologies Used

HTML5
CSS3
JavaScript
Node.js
Express
Mongoose
MongoDB

## Installation

Clone project and install:

git clone -b backend https://github.com/Alem-Dubcak/Web-Dev-Lab-8.git
cd Web-Dev-Lab-8/backEnd
npm install

## Running the Server

Run MongoDB, then start backend:

node server.js

Open studentManagement.html from the frontEnd folder to use the application.

## MongoDB Setup

Connect to MongoDB database:

mongodb://localhost:27017/studentManager

## How to Use the Application

1. Launch MongoDB.
2. Launch the backend server.
3. Launch the front-end program.
4. To establish a record, enter the student's name, major, course, and grades.
5. Use the records table to view student records.
6. To make changes to an existing record, use the edit option.
7. To get rid of a record, use the delete option.
8. To locate certain entries, use the search and filter tools.
9. Check out the statistics section for details on class performance.
10. To work with Excel files or create reports, utilize the import and export options.

## Main Features Implemented

Add, view, edit, and delete student records
MongoDB database storage
Automatic grade and pass/fail calculation
Dynamic course selection based on major
Input validation
Search and filtering
Class performance statistics and grade distribution
PDF and Excel report export
Excel import
Responsive user interface
